# 10 · index.html 缺陷评审与修复记录

> **文档性质**：工程评审与修复记录（不是科普文档），面向本项目维护者。
> **评审对象**：仓库根目录 `index.html`（2616 行 → 修复后 3408 行的单文件应用）、`tools/verify.mjs`
> **评审与修复日期**：2026-10-01
> **触发场景**：一位孕早期用户的真实就诊数据 —— hCG 276 IU/L、孕酮 14.16 nmol/L、TORCH 五项 IgM 全阴、
> 9/29–9/30 持续阴道出血（由褐色转为鲜红月经量伴血块）、**右侧下腹阵发性疼痛**、PCOS 月经不规律、**尚未做过 B 超**。
> **结论先行**：前端工程质量高于内容安全设计。存在 **1 处可复现的孕周 7 天错位**、**1 处预产期当天即宣告"宝宝已出生"的状态机错误**、
> **早孕危险信号覆盖不足**，以及**完全没有承载"化验单 + 出血"这条路径**。以上均已于本轮修复并有回归校验。

## 四、第二轮（2026-10-03）：生化妊娠暴露出的缺陷与修复

> **触发**：用户于 2026-10-02 被确认为**生化妊娠**（此前场景为 hCG 276 IU/L + 孕酮 14.16 nmol/L +
> 9/29–9/30 出血 + 右侧下腹阵发性疼痛，未做 B 超）。
> **结论**：第一轮修好了"过程中的信息支撑"，但没有修**状态机**——App 只会顺着"怀孕 → 产后"往下走，
> 一旦妊娠提前结束，它会继续逐周推送胎儿发育内容。这是本轮的核心缺陷。

### 4.1 缺陷与修复

| 编号 | 缺陷 | 为什么严重 | 修复 |
|---|---|---|---|
| **P0-4** | **只有"怀孕 → 产后"单向状态机，没有"妊娠结束"** | 记录结局前，App 会把"宝宝本周 · 葡萄 2.3 cm""预产期还有 213 天""建档 + NT 筛查"继续推给一个已经流产的人。这不是功能缺失，是对正在经历失去的人的直接伤害 | 新增 `state.outcome`（5 类结局 + 日期）与 `phaseNow().ended`；结束后**隐藏「周历」「产后月子」**，改为「恢复·备孕」；「今日」换成随访版 |
| **P0-5** | **顶部进度卡在结束后仍显示预产期与倒计时** | 同上，且是最刺眼的一处 | 结束后隐藏 `.progress-card`；头部改为「结局 · 第 N 天」，进度卡大数字不再是孕周 |
| **P0-6** | **没有"随访到 hCG < 5 IU/L"的闭环** | 初始表现是低 hCG + 出血 + **单侧腹痛**。在这种组合里，**只有 hCG 降到 <5 才能真正排除宫外孕 / 持续性异位妊娠**；被贴上"生化妊娠"标签并不会消除这个风险 | 化验单模块新增结束后专用规则：无结束后的结果 → 提醒必须复查；未达标 → 提示继续随访；**连续两次持平或上升 → 立即就诊**；达标 <5 → 不再提示 |
| **P0-7** | **红旗分诊没有"妊娠结束后"分组** | 结束后的危险信号（出血超月经量、发热、hCG 不降、剧烈腹痛）与孕期不同 | 新增「妊娠结束后」分组 5 条（含 `hCG 不降、平台、甚至上升` → 立即就诊） |
| **P1-5** | **全仓没有"生化妊娠 / 早期流产"的任何内容** | 用户只能自己去搜，容易被"保胎""免疫治疗"等无证据方案收割 | 新增「恢复·备孕」面板，内容全部取自本仓库证据底座 |
| **P1-6** | **没有"什么时候才需要系统检查"的阈值** | 单次流产不需要大检查，但**≥2 次就该启动评估**；不知道阈值会导致两种错误：白花钱做全套，或第二次后仍在等第三次 | 明确写入 **ASRM 2026：≥2 次妊娠失败（含生化妊娠，由 hCG 确认）即可启动评估，不必连续**，并附病因与检查方向表（docs/09 §4.2） |
| **P1-7** | **没有"不推荐做的检查"清单** | 流产后常被推销 NK 细胞、MTHFR、IVIg、父方白细胞免疫治疗——都是无证据或证据不足的项目，属于可预防的经济与身体伤害 | 单列一张卡：NK 细胞 / MTHFR / 无血栓史时的遗传性血栓筛查 / IVIg / 父方白细胞免疫治疗，均标注"不推荐"；并写明单次流产不需要常规卧床与"保胎"输液 |
| **P1-8** | **没有下一次备孕的可行动清单** | "下次怎么避免"是用户最真实的诉求 | 恢复页给出：叶酸 0.4 mg、TSH + TPOAb、空腹血糖 + HbA1c（PCOS 必查）、广东地贫筛查、维生素 D、体重与代谢、戒烟酒与咖啡因 <200 mg、慢性病用药不可自行停用；并给出再备孕时机（多数 1–2 次正常月经后，以医生意见为准） |
| **P1-9** | **没有早孕期失去的情绪支持路径** | App 原有情绪内容只覆盖产后抑郁（EPDS） | 增加"允许自己难过"的检查项与情绪卡：悲伤属正常反应；**持续 >2 周、影响生活，或出现伤害自己的想法 → 立即求助**；并说明专门的心理支持本身可改善下次妊娠结局（ESHRE / ASRM 承认 TLC） |
| **P2-5** | **docs/03 §3.2 的 RPL 定义与 docs/07 §5.4 冲突**（前者写"连续 ≥2 次（部分定义 ≥3 次）"） | docs/07 已把它标为"待修订点"；若照 docs/03 写进 App，会把"≥2 次即评估"错成"要等 3 次" | 按 ASRM 2026 统一为"**≥2 次妊娠失败即可启动评估（含生化妊娠，不必连续）**"，并把不推荐检查一并写入 docs/03 |
