# 10 · index.html 缺陷评审与修复记录

> **文档性质**：工程评审与修复记录（不是科普文档），面向本项目维护者。
> **评审对象**：仓库根目录 `index.html`（2616 行 → 修复后 3055 行的单文件应用）、`tools/verify.mjs`
> **评审与修复日期**：2026-10-01
> **触发场景**：一位孕早期用户的真实就诊数据 —— hCG 276 IU/L、孕酮 14.16 nmol/L、TORCH 五项 IgM 全阴、
> 9/29–9/30 持续阴道出血（由褐色转为鲜红月经量伴血块）、**右侧下腹阵发性疼痛**、PCOS 月经不规律、**尚未做过 B 超**。
> **结论先行**：前端工程质量高于内容安全设计。存在 **1 处可复现的孕周 7 天错位**、**1 处预产期当天即宣告"宝宝已出生"的状态机错误**、
> **早孕危险信号覆盖不足**，以及**完全没有承载"化验单 + 出血"这条路径**。以上均已于本轮修复并有回归校验。

## 一、修复清单（按严重程度）

| 编号 | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| **P1-1** | **孕周两套约定混用，全部内容提前 1 周** `currentWeek()` 用 `floor(days/7)+1`（"第 N 周"），但 `WEEKS` 里的胎儿数据是**临床孕周**口径（孕 7/8/9/10/11/12/13 周 CRL = 1.0/1.6/2.3/3.1/4.1/5.4/7.4 cm，是教科书 CRL 表） | 孕 7 周 0 天的用户看到"第 8 周 · 芸豆 1.6 cm"；"心脏开始跳动（已能用阴道超声看到）"出现在临床 4 周，诱导过早做 B 超后被告知"无胎心"而恐慌；早/中/晚孕三段分界全部提前 7 天 | 新增 `gestDays()` / `gestLabel()` / `weekIndexOf()` / `phaseNow()` 作为**唯一来源**，全部改为临床孕周；显示改为「孕 X 周 Y 天」；`trimesterOf()` 入参明确为临床孕周 |
| **P1-2** | **"按医生核定的孕周"回推 LMP 差 7 天** `readForm()` 原为 `lmp = ref − ((wk−1)*7 + dy)` | 医生 9/30 说"今天孕 9 周 3 天" → 真实 `lmp = ref − 66`，代码存 `ref − 59` → **预产期比医生核定的晚 7 天**；且"按预产期"与"按孕周"两个入口给出**不同**的预产期 | 公式改为 `lmp = ref − (wk*7 + dy)`，输入范围放宽到 `wk ≥ 0`（支持"孕 0 周"） |
| **P1-3** | **里程碑日期 off-by-one，同一个"预产期"在 App 内有两个日期** 时间线用 `lmp + week*7 − 7`（孕 40 周 → LMP+273），头部 `dueDate` 用 `lmp + 280` | 同屏相差 7 天；"大排畸（20–24 周）"落在临床 19 周 0 天、"糖耐（24–28 周）"落在临床 23 周 0 天，都早于窗口 | 统一为 `lmp + week*7`（临床孕 N 周从 LMP+N×7 开始），与 `dueDate` 共用同一基准 |
| **P1-4** | **预产期当天即显示"宝宝已出生"** `w > 40` 一律走产后分支，`inPostpartum()` 在 LMP+280 天返回 1；40 周后无内容，但表单允许填到 42 周 | 约 40% 的孕妇会过预产期，她们获得的是"产后第 1 周 · 宝宝已出生"；第 40 周自己写的警示"41 周未发动需评估引产时机"**永远显示不出来** | 新增 `phaseNow()` 的 **overdue 状态**（预产期 ~ 42 周）与**分娩日期输入**：未填分娩日期时，预产期后仍显示孕期内容 + 过期妊娠提醒，**孕 42 周（294 天）才兜底为产后**；填了出生日期则立即进入产后并按其计算产后周数 |
| **P0-1** | **宫外孕警示出现在风险最低处，高峰反而没有** 全 40 周仅 10 处 `warn`，宫外孕只在第 4 周出现一次，第 5/7/9 周为空 | 输卵管破裂高峰在临床 6–8 周，恰好落在警示消失区间；本次场景（hCG 276 + 出血 + 右侧痛）正落在这个盲区 | 第 4–12 周每周都保留宫外孕警示（含"不要等门诊号"与"hCG<1500 时看不到孕囊不能排除"） |

## 三、修复后的数据结构（供后续扩展）

```js
// localStorage: 'pregnancy-companion-v1'
state = {
  lmp: 'YYYY-MM-DD',        // 唯一孕周基准（其他输入方式都会换算到这里）
  dating: 'lmp'|'due'|'week',
  profile: { pcos, ama, multi, obese },
  delivery: 'YYYY-MM-DD',   // 可选：填了即进入产后模式
  labs: [ { id, date, hcg, prog, progUnit } ],   // 新增：化验单记录
}
// localStorage: 'pregnancy-companion-v1-checks'  （按天勾选，保留最近 60 天）
```

孕周相关函数（**新增代码一律用这几个，不要再自己算**）：

| 函数 | 语义 |
|---|---|
| `gestDays(lmp, ref)` | 孕龄天数（LMP 当天 = 0） |
| `gestLabel(days)` | 显示用「孕 X 周 Y 天」 |
| `phaseNow(ref)` | 当前阶段：`{ isPre, cw, weekIndex, overdue, delivered, ppWeek, toDue, due }` |
| `trimesterOf(cw)` | 入参为**临床孕周**，返回「孕早期 · 第 1-13 周」等 |
| `weekIndexOf(days)` | 查 `WEEKS` 的 1 基索引（孕 0 周复用第 1 周条目，40 周封顶） |
