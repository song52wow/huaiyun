## 使用提醒

1. **原始报告的证据强度未经二次核验**。成稿文档（上级目录）在整合时做了取舍与交叉核对，
   **当两者不一致时，以成稿为准**，并回到原始报告查看其引用来源再判断。
2. 原始报告中部分内容标注为"未找到权威来源""需核实"，
   **这些内容在成稿中同样被保留为"待核实点"，没有当作结论使用**。
3. 各报告末尾都有各自的"存疑/需核实点"清单，是继续深挖的入口。
4. 政策类内容的时效性以**成稿第 05 章标注的日期**为准，本目录文件可能更早。
