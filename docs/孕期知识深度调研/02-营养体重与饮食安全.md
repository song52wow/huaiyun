# 02 · 孕期营养、体重管理与饮食安全

> 本章依据：中国营养学会《中国居民膳食营养素参考摄入量（2023版）》与《中国居民膳食指南（2022）》、

## 2.1 先破一个最大的误区

> **"一个人吃，两个人补"是错的。孕早期不需要增加任何热量，整个孕期额外能量大约只相当于每天多一杯奶 + 一个鸡蛋 + 一份水果。**

| 时期 | 额外能量 | 额外蛋白质 |
|---|---|---|
| 孕早期（0～12 周） | **不需要增加** | 不需要增加 |
| 孕中期（13～27 周） | **+250 kcal/d** | **+15 g/d** |
| 孕晚期（28～40 周） | **+400 kcal/d** | **+30 g/d** |

换算成食物（《中国居民膳食指南（2022）》口径）：

- 孕中期 ≈ 在孕前平衡膳食基础上，每天**加奶 200 g、肉类 50 g、水果 100 g**；
- 孕晚期 ≈ 每天**加奶 250 g、肉类 100 g、薯类 50 g、水果 100 g**。

📌 **注**：《中国居民膳食营养素参考摄入量（2023版）》把孕中、晚期的额外能量各下调了 50 kcal
（旧版分别为 300 / 450 kcal），蛋白质推荐量与旧版一致。

> 来源：[广东省人民医院临床营养科《新版孕妇膳食供给和推荐量》](https://www.thepaper.cn/newsDetail_forward_26207407) ·
> [中国营养学会 DRIs 官网](https://www.cnsoc.org/drpostand/)

## 2.2 关键营养素速查（中国标准）

| 营养素 | 孕期推荐 | 关键要点 |
|---|---|---|
| **叶酸** | 孕妇 RNI **600 µg 叶酸当量/d** | 通过**叶酸制剂补 400 µg/d**，**最好孕前 3 个月开始**；《孕前和孕期保健指南》写"补充叶酸 0.4～0.8 mg/d，至孕 3 个月，有条件者可继续服用含叶酸的复合维生素"。**既往生育过神经管缺陷（NTD）儿者：每日 4 mg** |
| **铁** | 孕早期 **18 mg/d**；孕中期 **25 mg/d**；孕晚期 **29 mg/d**（2023 版较 2013 版上调） | 见 2.3 节：中国**不推荐常规预防性补铁**，按 Hb/SF 结果决定 |
| **钙** | 与同龄女性一致，**800 mg/d**（2023 版不再建议孕期额外增加） | ⚠️ 与《孕前和孕期保健指南（2018）》"孕中期起常规补充钙剂 0.6～1.5 g/d"存在口径差异，见 2.4 节 |
| **维生素 D** | **10 µg/d（400 IU）**；UL 50 µg/d | 户外日照有助于合成；不必盲目大剂量补 |
| **碘** | 孕妇 **230 µg/d**；**UL 500 µg/d** | 使用**加碘盐** + 每周 1～2 次海产品；**海带/紫菜碘含量极高，需限量**（见 2.6）。**沿海地区也不能靠海产品替代碘盐** |
| **DHA + EPA** | AI **0.25 g/d**，其中 **DHA 0.2 g/d** | 每周吃 2～3 次鱼，其中至少 1 次为富含脂肪的**低汞海鱼**；不吃鱼者可考虑藻油 DHA |
| **维生素 A** | 孕早期 **660 µg RAE/d**；孕中晚期 **730 µg RAE/d**；**UL 3000 µg RAE/d** | **动物肝脏维生素 A 极高**：建议每周 ≤1 次、每次 ≤50 g，或避免；优先 β-胡萝卜素来源（胡萝卜、南瓜、深绿蔬菜） |
| 锌 | 10.5 mg/d（UL 40） | 红肉、贝类、坚果 |
| 膳食纤维 | 孕中期起 **29～34 g/d** | 全谷、豆类、蔬果；配合足量饮水 |
| 蛋白质 | 孕早 55 g/d；孕中 **70** g/d；孕晚 **85** g/d | 比孕前分别 +15 / +30 g/d |
| **水** | 非孕女性 1500 ml/d；**孕中晚期 1700 ml/d**（孕早期与孕前一致） | 不是"越多越好"；分次小口喝。⚠️ 本项目 index.html 写的"1700–1900 ml"上限偏高，以 **1700 ml** 为基准更准确 |

**读表提示**
- **RNI（推荐摄入量）是"绝大多数人应达到"的目标，不是"越多越好"**；表右列 UL 才是安全上限；
- **钙的 800 mg/d 是总摄入量**（含食物），不是"要额外吃 800 mg 钙片"；
- **叶酸 600 µg DFE/d 是总当量**，其中建议由**制剂补充 400 µg**；
- **碘 UL 500 µg/d**：这意味着一周吃几次海带/紫菜汤就可能接近或超过上限——
  加碘盐 + 正常饮食已足够，**不需要额外大量补海带**。

## 2.3 铁与贫血：中国最新的循证口径

来源：中华预防医学会生命早期发育与疾病防控专业委员会、中华医学会围产医学分会、
中华医学会妇产科学分会产科学组《**孕产妇血液管理专家共识**》（中华围产医学杂志 2026,29(2):97-104）

**中国数据**
- 妊娠期**贫血发生率 17.3%**，其中**铁缺乏发生率高达 45.6%**；
- 妊娠期共需铁约 **1000 mg**，需求量由孕早期 **0.8 mg/d** 升至孕中晚期 **6.3 mg/d**；
- 产前 **Hb 每下降 10 g/L，产后出血风险增加 25%**。

**诊断标准（中国 vs 国际）**

| | 妊娠期贫血 | 铁缺乏（SF） |
|---|---|---|
| **中国** | **Hb <110 g/L**（各孕期统一） | **SF <20 µg/L** |
| WHO / 美国 | 孕早 <110、孕中 <105、孕晚 <110 g/L | WHO <15 µg/L；美/英/澳 <30 µg/L |
| 英国 | 孕早 <110，孕中晚 <105 g/L | — |

**筛查时机（强推荐）**：所有孕妇在**妊娠早、中、晚期**筛查；
**妊娠 28～32 周、36 周以及分娩前**做血常规；高危人群（长期素食、孕前低体重、慢性肾病、胃溃疡、
多胎、胎盘植入/前置胎盘等）重点关注。有条件者查 SF。

**治疗**
- **不推荐常规预防性补铁**（缺乏我国流行病学证据）；
- **口服补铁是一线**：确诊 IDA 者每日 **100～200 mg 元素铁**，2 周后复查 Hb 评估疗效；
  非贫血但 **SF<30 µg/L** 者每日 **60 mg 元素铁**，8 周后评估；
- **口服无效的定义**：治疗 2 或 4 周后 Hb 提升分别 **<10 或 <20 g/L**；
  不能耐受、依从性差或无效者，**孕中晚期可选静脉铁剂**（妊娠最初 3 个月建议只用口服）；
- **Hb <70 g/L 建议输注浓缩红细胞**；
- 纠正后 Hb 正常，仍应**继续口服补铁 ≥3 个月**补足储备；
- ⚠️ Hb 也**不是越高越好**：Hb <100 或 >145 g/L 与早产、新生儿呼吸窘迫风险呈 **U 形曲线**。

**饮食配合**
- 富铁食物：**动物血、肝脏、红肉**（血红素铁吸收率高）；
- **维生素 C** 促进非血红素铁吸收；
- **咖啡、茶抑制铁吸收，避免与铁剂/富铁餐同时**；
- 补钙与补铁**错开 2 小时以上**。

## 2.4 钙的"两个口径"怎么看

这是孕期营养里最容易被问倒的一个矛盾：

| 来源 | 说法 |
|---|---|
| 《中国居民膳食营养素参考摄入量（2023版）》 | 孕期钙摄入量**不额外增加**，与同龄女性一致（800 mg/d）。理由：补钙不影响母体及婴儿骨健康，怀孕次数不影响中老年骨健康 |
| 《孕前和孕期保健指南（2018）》 | **妊娠 14～19⁺⁶ 周起"开始常规补充钙剂 0.6～1.5 g/d"** |

**怎么理解**：前者说的是"**总摄入量需要多少**"，后者说的是"**临床上常规开多少补充剂**"。
我国传统膳食每天约提供钙 400～500 mg，距 800 mg 还有缺口，因此很多医院会直接开钙片。
两者不矛盾，但**具体补多少应由产检医生结合你的饮食情况决定**——不要自行叠加多种钙剂。

**食物来源优先级**：奶及奶制品（最好来源）＞ 大豆及豆制品 ＞ 深绿色蔬菜、菜花。
⚠️ 苋菜、菠菜、空心菜虽含钙高，但**草酸多、吸收率低**，不宜作为补钙首选。

## 2.5 孕期体重增长：中国国标（WS/T 801-2022）

国家卫生健康委 2022 年 7 月发布、**2022 年 10 月实施**，适用于**单胎自然妊娠**。

| 孕前 BMI 分类 | BMI 范围（kg/m²） | **总增重推荐范围（kg）** |
|---|---|---|
| 低体重 | <18.5 | **11.0 ～ 16.0** |
| 正常体重 | 18.5 ～ <24.0 | **8.0 ～ 14.0** |
| 超重 | 24.0 ～ <28.0 | **7.0 ～ 11.0** |
| 肥胖 | ≥28.0 | **5.0 ～ 9.0** |

⚠️ **注意中国 BMI 切点与欧美不同**：中国超重从 **24.0** 起、肥胖从 **28.0** 起；
而 IOM（美国）标准是正常 18.5～24.9、超重 25～29.9、肥胖 ≥30。
所以**不能用美国 App 的增重建议直接套用**。

**增重速率参考**：孕早期约 0～2 kg；孕中晚期按孕前 BMI 每周约 **0.2～0.5 kg**
（低体重偏高、肥胖偏低）。**"每周固定增 0.5 kg"是偏高且容易误导的说法。**

**增重不足/过多的风险**
- 增重不足：低出生体重、早产、胎儿生长受限；
- 增重过多：妊娠期糖尿病、子痫前期、巨大儿、难产与剖宫产、产后体重滞留。

> 来源：[佛山市妇幼保健院对 WS/T 801-2022 的介绍](https://www.fsfy.com/Content-48613.html)

## 2.6 饮食安全：分"真风险"和"焦虑风险"

### 2.6.1 真风险清单（有明确病原学依据，必须避免）

| 风险 | 高危食物 | 怎么做 |
|---|---|---|
| **李斯特菌** | 未经巴氏杀菌的奶及奶酪（生乳奶酪、软质奶酪）、**即食冷切肉/熟食卤味（尤其冰箱取出直接吃）**、烟熏海鲜、未彻底加热的剩菜、未洗净的生蔬 | 熟食**彻底加热到冒热气再吃**；剩菜 24 小时内吃完并彻底加热；生熟砧板分开；冰箱定期清洁 |
| **弓形虫** | 生肉/半生肉、未洗净蔬果、**接触猫砂/土壤** | 肉彻底煮熟（中心温度 ≥71 ℃）；处理生肉后洗手；蔬果洗净；**不要自己清理猫砂**（让别人做，或戴手套并洗手）；园艺戴手套 |
| **沙门氏菌 / 大肠杆菌** | **生鸡蛋/溏心蛋、生鱼片、生腌海鲜（潮汕生腌）、未消毒果汁/生奶** | 只吃全熟蛋；避免生食水产 |
| **汞** | **鲨鱼、剑鱼（旗鱼）、大耳马鲛、方头鱼、金枪鱼（大目/蓝鳍）等大型掠食性鱼类** | 见下方分级 |
| **酒精** | 一切含酒精饮品、酒酿/醪糟、含酒药膳 | **没有安全剂量，孕期 0 容忍**（FASD 是唯一可 100% 预防的出生缺陷类型） |
| **咖啡因** | 咖啡、浓茶、奶茶、可乐、能量饮料、部分巧克力 | **每日 <200 mg**。参考：中杯美式约 150～200 mg，速溶 1 杯约 60～80 mg，**一杯奶茶就可能接近甚至超过上限**——奶茶是广东孕妈最常忽略的咖啡因来源 |
| **肝吸虫等寄生虫** | **顺德鱼生、生腌、醉虾醉蟹** | 广东地区尤其注意：淡水鱼生是肝吸虫（华支睾吸虫）主要感染途径 |

### 2.6.2 鱼类怎么吃：一个可操作的分级

| 级别 | 例子 | 建议 |
|---|---|---|
| ✅ 放心吃（低汞、富 DHA） | 三文鱼（养殖/大西洋鲑）、沙丁鱼、鲱鱼、鳕鱼、鲈鱼、鲳鱼、龙利鱼、罐装淡金枪鱼 | **每周 2～3 份**（1 份 ≈ 手掌大小，约 100～120 g） |
| ⚠️ 限量 | 长鳍金枪鱼（白金枪）、黄鳍金枪鱼、石斑鱼、马鲛鱼（部分种类） | 每周不超过 1 份 |
| ❌ 避免 | 鲨鱼、剑鱼/旗鱼、大耳马鲛、方头鱼、大目金枪鱼 | 孕期完全避免 |

⚠️ **"深海鱼"是一个营销词，不是安全等级**。三文鱼、鳕鱼多为低汞可吃；
真正要避的是**大型掠食性鱼类**。不吃鱼者可补充藻油 DHA 200 mg/d。

> 参考：[FDA/EPA "Advice about Eating Fish"](https://www.fda.gov/food/consumers/advice-about-eating-fish)（建议以官网最新版为准）

### 2.6.3 广东特色饮食的安全提示

| 本地习惯 | 风险 | 建议 |
|---|---|---|
| **生腌（潮汕生腌蟹/虾/血蚶）** | 副溶血弧菌、创伤弧菌、寄生虫、李斯特菌 | 孕期避免 |
| **顺德鱼生** | **华支睾吸虫（肝吸虫）**。广东省感染人数曾超 **500 万**，顺德感染率一度达 **50.74%** | 孕期尤其要**彻底煮熟**；淡水鱼生是广东最重要的本地食源性寄生虫风险 |
| **凉茶（癍痧、廿四味等）** | 含多种草药，成分与剂量不受监管，部分活血/寒凉 | **孕期避免** |
| **生木薯、口服芦荟** | 生木薯含氰苷；口服芦荟有刺激子宫与致泻风险 | **避免** |
| **老火汤** | "营养在汤里"是误区（蛋白质主要在肉里，汤里多为脂肪、嘌呤、盐）；长时间熬煮不产生额外营养 | 可以喝，但**别替代吃肉**；控盐；痛风/高尿酸者少喝 |
| **薏米水、桂圆、当归、红花类药膳** | 中医认为活血/滑胎，现代证据不足 | **谨慎，先咨询产科或中医师**；避免红花、麝香、大黄、番泻叶 |
| **糖水、奶茶** | 高糖 + 咖啡因 | 妊娠糖尿病或体重增长过快者避免 |
| **现挤"生鲜奶"** | 布鲁氏菌、李斯特菌 | 必须煮沸后饮用；不建议 |

## 2.7 常见"忌口"传说的循证评价

| 说法 | 结论 | 说明 |
|---|---|---|
| 不能吃螃蟹 | ❌ 无依据 | 蟹肉本身安全，**关键是彻底煮熟**；蟹黄胆固醇高，适量即可 |
| 不能吃芒果/荔枝/龙眼 | ⚠️ 部分有道理 | 不是"有毒"，而是**糖分极高**——控糖者需限量；过敏体质者注意 |
| 不能吃兔肉（会兔唇） | ❌ 完全无依据 | 民间附会 |
| 不能吃辣椒 | ❌ 无依据 | 但会加重烧心/胃食管反流，按自身耐受 |
| 不能吃酱油（宝宝会黑） | ❌ 无依据 | 肤色由遗传决定 |
| 不能吃"寒凉"食物 | ⚠️ 中医概念 | 现代营养学无对应证据；如引起腹泻或不适则避免 |
| 不能用微波炉/电磁炉 | ❌ 无依据 | 非电离辐射，合格产品正常使用安全 |
| 不能染发 | ⚠️ 证据有限 | 现有研究未证实明确致畸；但建议**孕早期避免**，之后选通风良好、正规产品、避免接触头皮 |
| 不能拍 X 光/CT | ⚠️ 过度简化 | **必要的诊断性检查可以做**，多数部位胎儿剂量远低于风险阈值；关键是告知医生已怀孕，由医生权衡。**不要因为"怕辐射"拒绝必要的急诊检查** |
| 不能过安检/用手机/WiFi | ❌ 无依据 | 均为非电离辐射，剂量极低 |
| 不能性生活 | ❌ 过度简化 | 正常妊娠可进行；**前置胎盘、阴道出血、已破水、有早产风险时禁止** |
| 不能坐飞机 | ❌ 过度简化 | 孕 14～28 周最适宜；多数航空公司规定 28～32 周后需证明、36 周后不予承运（各公司不同，订票前确认） |
| 不能泡温泉/桑拿 | ✅ 有依据 | 核心温度过高（>38.9～39 ℃）与神经管缺陷相关；**避免长时间高温环境**，淋浴水温 <40 ℃、时间短 |
| 不能运动 | ❌ 完全错误 | 见第 05 章：ACOG/WHO 均建议孕期规律中等强度运动 |
| 不能趴睡 | ⚠️ 孕中晚期 | 孕晚期避免仰卧（下腔静脉受压）；"左侧卧最佳"有生理学依据但**证据等级不高**——醒来发现平躺不必恐慌，翻回侧卧即可 |
| 不能用牙科麻药/看牙 | ❌ 错误 | 孕期牙龈炎常见，**孕中期是治疗窗口**；局麻、必要 X 线（带防护）是安全的。**口腔感染不治的风险更大** |
| 不能养猫 | ⚠️ 有条件 | 弓形虫主要经**猫砂与生肉**传播；不清理猫砂、不喂生肉、戴手套做园艺即可 |

## 2.8 常见不适的饮食与营养处理

| 症状 | 处理 |
|---|---|
| **孕吐 / 晨吐** | 少食多餐；起床前先吃几片苏打饼干；**生姜**、维生素 B6（10～25 mg，每日 3 次）有证据支持；避免油腻与强烈气味；保证水分 |
| **妊娠剧吐** | ⚠️ 无法进食饮水、体重下降、尿少色深、酮体阳性 → **就医**（可能需要静脉补液与止吐药，如多西拉敏-吡哆醇、昂丹司琼等，遵医嘱） |
| **便秘** | 膳食纤维 25～30 g/d + 足量饮水 + 规律活动；**乳果糖、聚乙二醇**可在医生指导下使用；避免长期用番泻叶等刺激性泻药 |
| **烧心 / 胃食管反流** | 少食多餐；睡前 2～3 小时不进食；**抬高床头 15～20 cm**；避免辛辣、咖啡、巧克力、柑橘；抗酸剂（含钙/镁）或藻酸盐类可短期用，**避免含铝/碳酸氢钠的制剂** |
| **腿抽筋** | 补钙/镁的证据有限；拉伸、热敷、避免久站更有效 |
| **下肢水肿** | 抬高下肢、左侧卧、弹力袜、控盐。⚠️ **突发单侧肿痛要排除深静脉血栓**；**水肿 + 头痛/视物模糊/血压升高要排除子痫前期** |
| **缺铁性贫血** | 见 2.3 节 |
| **妊娠期糖尿病** | 分餐（3 主餐 + 2～3 加餐）、控制精制碳水、选低 GI、餐后活动 20～30 分钟、必要时胰岛素；**不要自行节食**（会生酮，对胎儿不利） |

## 2.9 特殊人群

- **素食孕妇**：重点盯 **维生素 B12**（植物性食物几乎不含，必须强化食品或补充剂）、铁、锌、钙、DHA、蛋白质；严格素食者建议营养科会诊。
- **乳糖不耐受**：选舒化奶、酸奶、奶酪，或分次少量饮奶；必要时钙剂补充。
- **食物过敏**：孕期**不需要预防性回避**常见致敏食物（无证据显示能预防子代过敏）；但自身严重过敏者需随身携带急救药物并告知产科医生。
- **减重手术后**：营养缺乏风险高，需专科随访，重点监测铁、B12、叶酸、钙、维 D、蛋白质。
- **双胎妊娠**：能量、蛋白质、铁、钙、DHA 需求均高于单胎，增重目标不同（**不适用 WS/T 801-2022，需专科评估**）。
