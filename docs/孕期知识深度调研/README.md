## ⚡ 最该先记住的 20 条

1. **产检框架**：中国指南为 7 个孕周节点、共 **7～11 次**；基层另有 **5 次免费随访**，两者并行不替代。
2. **关键窗口别错过**：6～8 周看宫内，**11～13⁺⁶ 周 NT**，12～22⁺⁶ 周 NIPT，16～22 周羊穿，**20～24 周大排畸**，**24～28 周糖耐**，35～37 周 GBS，37 周起每周胎监。
3. **建档要早**：理想 **孕 6～12 周**，最迟不晚于 13 周，否则错过 NT 与早唐。
4. **广东必查地贫**：国家指南点名广东为地贫筛查地区，夫妇双方都要做。
5. **叶酸**：孕前 3 个月起 0.4～0.8 mg/d 至孕满 3 个月；**曾生育神经管缺陷儿者 4 mg/d**。
6. **铁**：中国**不推荐常规预防性补铁**；按 Hb/SF 决定（**SF<30 → 60 mg/d；确诊 IDA → 100～200 mg/d 元素铁**）。
7. **贫血标准**：中国妊娠期贫血统一为 **Hb<110 g/L**；铁缺乏 **SF<20 µg/L**（WHO<15，美英澳<30）。
8. **钙**：中国 2023 版**不再建议孕期额外加钙**（总摄入 800 mg/d），但保健指南仍写"孕中期起常规补钙剂"——**遵医嘱，别自行叠加**。
9. **增重看国标**：WS/T 801-2022（低体重 11～16 kg / 正常 **8～14 kg** / 超重 7～11 kg / 肥胖 5～9 kg），**中国 BMI 切点是 24 / 28，与欧美不同，不能混用**。
10. **热量**：孕早期**不需要**额外热量；孕中期 +250 kcal/d、孕晚期 +400 kcal/d。"一人吃两人份"是错的。
11. **真正必须避免的**：**酒精（0 容忍）**、生鱼生肉生腌、未巴氏杀菌乳制品、即食冷切与冷藏烟熏鱼、**大型掠食性鱼类（鲨鱼/剑鱼/旗鱼）**、生木薯、口服芦荟、**凉茶**。
12. **咖啡因 <200 mg/d**——注意**一杯奶茶就可能接近上限**。
13. **酱油高血压危险信号**：**头痛 + 视物模糊 + 上腹/右上腹痛 → 立即就医**（重度子痫前期/HELLP）。
14. **子痫前期诊断**：BP ≥140/90 **且**（尿蛋白 ≥0.3 g/24 h 或 P/Cr ≥0.3 或随机 ≥+）**或**无蛋白尿但伴器官受累。**≥160/110 是重度**。阿司匹林预防从 **12～16 周**开始（剂量遵医嘱）。
15. **胎动**：计数是为了熟悉宝宝规律，**不是数字达标就安全**；**AFFIRM 试验显示结构化计数并未降低死产**——**"感觉不对就去医院"才是关键**。
16. **ICP 只表现为痒**：**手掌脚掌瘙痒、夜间加重、无皮疹 → 查空腹总胆汁酸**。
17. **用药第一原则**：**绝对不要自行停用慢性病药物**；FDA 旧 A/B/C/D/X 分级已废止（PPLR 取代）。
18. **疫苗**：**流感疫苗推荐（孕妇是优先人群）**、Tdap 常于 27～36 周；**减毒活疫苗孕期禁用**。
19. **产后血栓**：产后 6 周内均为风险窗口，**"坐月子不下床"会显著抬高这一风险**；单侧小腿肿痛要急诊。
20. **产后抑郁可治**：中国围产期抑郁发生率 **3.8%～16.7%**；**出现伤害自己或宝宝的想法 → 立即就医**。

## 🚨 红旗信号（精简版，完整版见第 03 章 3.1 节）

**立即急诊 / 打 120**

- 阴道出血（超过点滴）
- 突发单侧下腹剧痛 + 出血 + 头晕（**警惕宫外孕**）
- 持续剧烈腹痛 / 肚子发硬不缓解
- **持续头痛 + 视物模糊 + 上腹或右上腹疼痛**
- 抽搐、意识丧失
- **胎动明显减少或消失**
- 破水、规律宫缩（<37 周）
- 发热 ≥38 ℃
- 呼吸困难、胸痛、咯血
- **单侧小腿肿胀疼痛**（血栓）
- 产后出血量超过月经量、大血块
- 产后剧烈头痛/抽搐（**产后迟发子痫前期**）
- **出现伤害自己或宝宝的想法**

**24 小时内就诊**：全身瘙痒（尤其手掌脚掌）· 血压 ≥140/90 · 水肿突然加重 · 无法进食饮水的剧吐 · 明显头晕心悸面色苍白 · 尿频尿痛腰痛

## 🔍 中国 vs 国际：十个必须知道的差异

| # | 议题 | 中国 | 国际 |
