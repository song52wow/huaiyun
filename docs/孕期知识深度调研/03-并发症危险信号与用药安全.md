## 3.1 红旗信号速查表（最重要的一节）

### 3.1.1 立即去急诊 / 打 120（不要等、不要先上网查）

| 信号 | 要怀疑什么 | 立刻怎么做 |
|---|---|---|
| **阴道出血**（任何孕周，量超过点滴） | 流产、异位妊娠、前置胎盘、胎盘早剥、临产见红 | 立即急诊；**若无痛性出血，禁阴道检查、禁性生活** |
| **突发单侧下腹剧痛 + 出血 + 头晕/晕厥** | **异位妊娠破裂**（可致命） | 打 120，不要自行开车 |
| **持续剧烈腹痛 / 肚子发硬不缓解** | 胎盘早剥、子宫破裂、急性阑尾炎、卵巢扭转 | 立即急诊，备血、胎心监护 |
| **持续头痛 + 视物模糊/闪光 + 上腹或右上腹疼痛** | **重度子痫前期 / HELLP** | 立即测血压，急诊查血小板、肝酶、LDH |
| **血压 ≥160/110 mmHg** | 重度子痫前期 / 高血压急症 | **15 分钟内复测，即急诊**（降压 + 入院） |
| **抽搐、意识丧失** | **子痫**（产科急症） | 打 120；**侧卧位保持气道**，勿强行按压肢体 |
| **胎动明显减少或消失** | 胎儿窘迫、胎盘功能不全 | 立即胎心监护 + 超声，**不要等到第二天** |
| **胎动突然剧烈增多后骤减** | 急性胎儿窘迫、**脐带真结/绕颈** | 立即急诊 |
| **破水**（阴道流液，不受控制） | 胎膜早破 → 感染与脐带脱垂风险 | **平卧、垫高臀部**，急诊；避免盆浴与性生活 |
| **规律宫缩（<37 周）** | 早产 | 立即急诊，评估宫颈、fFN、胎儿监护 |
| **发热 ≥38 ℃**（伴宫缩/腹痛更危险） | 绒毛膜羊膜炎、肾盂肾炎、感染 | 急诊，抗生素，评估是否需终止妊娠 |
| **呼吸困难、端坐呼吸、粉红色泡沫痰、胸痛、咯血** | 肺水肿、围产期心肌病、肺栓塞 | 立即急诊 |
| **单侧小腿肿胀疼痛、发红发热** | 深静脉血栓（DVT）→ 肺栓塞风险 | 立即急诊查下肢血管超声；**勿按摩** |
| **大量阴道流血（超过月经量）或大血块** | 产后出血 | 打 120，按摩子宫，不要等待 |
| **产后剧烈头痛、视物模糊、抽搐** | **产后迟发子痫前期 / 子痫**（可发生在产后 6 周内） | 立即急诊 |
| **产后情绪持续低落 >2 周，或出现伤害自己/宝宝的想法** | 产后抑郁 / **产后精神病（急症）** | 立即就医；**有伤害念头属急症** |

### 3.1.2 24 小时内就诊（不必叫救护车，但不要拖）

| 信号 | 可能原因 |
|---|---|
| 全身瘙痒，**尤其手掌脚掌**，夜间加重，无皮疹 | **妊娠期肝内胆汁淤积症（ICP）** |
| 血压自测 ≥140/90 mmHg | 妊娠期高血压疾病 |
| 水肿突然加重（尤其面部、双手）+ 体重短期骤增 | 子痫前期 |
| 孕吐严重到无法进食饮水、尿少色深 | 妊娠剧吐、脱水、酮症 |
| 明显头晕、心悸、面色苍白、活动后气促 | 贫血 |
| 尿频尿痛尿急、腰痛 | 尿路感染 / 肾盂肾炎 |
| 阴道分泌物异常增多、异味、伴瘙痒 | 阴道感染 |
| 视物模糊但无头痛 | 需排除血压、血糖、眼底问题 |
| 严重便秘、痔疮剧痛、无法缓解的呕吐腹泻 | 需评估 |

### 3.1.3 "不必恐慌，但要留意"

| 情况 | 说明 |
|---|---|
| 少量褐色分泌物、无腹痛（孕早期） | 可能是着床出血或宫颈敏感，**但需超声确认宫内妊娠后**才能安心 |
| 短暂、不规律、不伴疼痛的肚子发紧 | 假宫缩（Braxton Hicks），休息后缓解 |
| 偶发胎动减少，喝点水、左侧卧后恢复 | 需观察，但**若再次出现或持续，仍应就诊** |
| 孕晚期轻度踝部水肿、傍晚加重，晨起消退 | 常见生理现象；**若为突发单侧或伴头痛则性质不同** |
| 妊娠纹、脱发、鼻塞、牙龈出血、烧心 | 常见的孕期生理变化 |

## 3.2 早期妊娠问题

### 3.2.1 流产

- **发生率**：临床确认妊娠后约 10%～20% 以流产告终；**其中约 50%～60% 与胚胎染色体异常有关**；
- **分类**：先兆流产（出血/腹痛但宫口未开、妊娠物未排出）、难免流产、不全流产、完全流产、稽留流产（胚胎停育）、复发性流产；
- **诊断阈值**（避免过度诊断）：妊娠囊 **≥25 mm 无胚芽**，或胚芽 **≥7 mm 无心跳**；
- **处理**：期待治疗、药物（米索前列醇/米非司酮）、手术（负压吸引/钳刮）。**具体取决于孕周、出血量、感染风险与患者意愿**；
- **复发性流产**：通常指连续 **≥2 次**（部分定义 ≥3 次）妊娠失败；需系统检查
  （夫妻染色体、抗磷脂抗体、子宫结构、甲状腺功能、糖代谢等）。

### 3.2.2 异位妊娠（宫外孕）——必须认识

- **典型三联征**：停经 + 腹痛 + 阴道出血；但**很多病例不典型**；
- **危险因素**：既往异位妊娠、输卵管手术/炎症、盆腔炎、辅助生殖、宫内节育器、吸烟；
- **诊断**：血 hCG 序列 + 经阴道超声。**hCG 达 3500 mIU/mL 仍未见于宫内妊娠囊需高度警惕**；
- **处理**：甲氨蝶呤（MTX，适用于早期、血流动力学稳定、无破裂者）或手术（腹腔镜输卵管切除/开窗），
  **破裂出血属急症**；
- ⚠️ **本手册 index.html 第 4 周已正确提示"单侧剧痛 + 出血立即就医"，这一条要保留并强化。**

### 3.2.3 妊娠滋养细胞疾病（葡萄胎等）

- 表现：hCG 异常升高、超声"落雪状/蜂窝状"、阴道排出水泡状组织、孕吐剧烈；
- **必须清宫 + 病理 + hCG 随访**（随访期通常 6 个月～1 年，期间需可靠避孕）；
- 少数进展为侵蚀性葡萄胎/绒癌，需化疗。

### 3.2.4 宫颈机能不全

- 特征：既往妊娠中孕期无痛性宫颈扩张导致流产/早产；
- 诊断与处理：**经阴道超声监测宫颈长度**、宫颈环扎术（有明确指征时）、阴道孕酮；
- **孕中期宫颈长度筛查**对早产高危者有预测价值（临界值常取 **<25 mm**；具体处理见 3.5 节）。

### 3.2.5 "保胎"的循证评价（重要，能减少大量无效焦虑）

| 措施 | 证据结论 |
|---|---|
| **卧床休息** | ❌ **无证据**显示能预防流产或早产；反而增加血栓、肌力下降、骨质流失与心理负担 |
| **黄体酮（孕酮）** | ⚠️ **有选择性指征**：对**有先兆流产症状且既往有流产史**者，部分指南与共识支持使用；对**无出血、无高危因素**者无明确获益。**是否用、用哪种、用多久必须由医生决定** |
| **补充维生素/中药"保胎丸"** | ❌ 多数缺乏证据；部分中药含活血成分，孕期安全性不明 |
| **HCG 治疗** | ❌ 无证据支持 |
| **宫颈环扎** | ✅ 仅对明确指征（如既往孕中期流产史 + 宫颈缩短）有效 |

> **一句话**：绝大部分早期流产是胚胎自身染色体异常导致的**自然淘汰，不是"没保好"**。
> 卧床不能改变结局，但会显著降低孕妇的生活质量。

## 3.3 妊娠期高血压疾病（中国 2020 指南）

### 3.3.1 分类与诊断标准

中国指南将其分为 **4 类**：

| 类型 | 诊断要点 |
|---|---|
| **妊娠期高血压** | 妊娠 **20 周后**首次出现 **SBP ≥140 和/或 DBP ≥90 mmHg**，**尿蛋白阴性**；**产后 12 周内**恢复正常。**≥160/110 为重度妊娠期高血压** |
| **子痫前期** | 妊娠 20 周后 **BP ≥140/90**，**且**有下列任一项：①尿蛋白定量 **≥0.3 g/24 h**；②尿蛋白/肌酐比值 **≥0.3**；③随机尿蛋白 **≥(+)**；**或**无蛋白尿但伴**任一器官/系统受累**（心、肺、肝、肾、血液、消化、神经）或胎盘-胎儿受累。**子痫前期也可发生在产后** |
| **子痫** | 子痫前期基础上发生、**不能用其他原因解释的强直性抽搐**；可发生在产前、产时或产后，也可在无典型子痫前期表现时发生 |
| **妊娠合并慢性高血压** | 妊娠 20 周前已存在高血压，或妊娠 20 周后首次发现但**持续到产后 12 周以后** |
| **慢性高血压伴发子痫前期** | 慢性高血压孕妇妊娠 20 周后新出现蛋白尿（≥0.3 g/24 h 或随机 ≥+），或原蛋白尿明显增加，或出现重度子痫前期的任一表现 |

**重度子痫前期的判定（出现任一即为重度）**
1. 血压持续升高不可控制：**SBP ≥160 和/或 DBP ≥110 mmHg**；
2. **持续性头痛、视觉障碍**或其他中枢神经系统异常表现；
3. **持续性上腹部疼痛**及肝包膜下血肿或肝破裂表现；
4. **转氨酶升高**（ALT 或 AST）；
5. **肾功能受损**：尿蛋白定量 >2.0 g/24 h；少尿（24 h 尿量 <400 ml 或每小时 <17 ml）；血肌酐 **>106 µmol/L**；
6. 低蛋白血症伴腹水、胸水或心包积液；
7. **血液系统异常**：血小板持续下降并 **<100×10⁹/L**；微血管内溶血（贫血、LDH 升高、黄疸）；
8. 心功能衰竭；9. 肺水肿；
10. **胎儿生长受限或羊水过少、胎死宫内、胎盘早剥**等。

**早发子痫前期**：需在**妊娠 34 周前**因子痫前期终止妊娠者。

### 3.3.2 血压测量（这决定了你会不会被"误诊"）

- 测量前**安静休息至少 5 分钟**；取坐位或卧位；袖带大小合适；**通常测右上肢**，袖带与心脏同高；
- **同一手臂至少 2 次**测量 SBP ≥140 和/或 DBP ≥90 才能诊断；
- **首次发现血压升高者，应间隔 4 小时或以上复测**；
- 重度（≥160/110）者**间隔数分钟重复测定即可诊断**；
- **"白大衣高血压"很常见**：诊室高、在家正常。建议**家庭血压监测**，有条件者做 24 小时动态血压；
- ⚠️ 血压较基础值升高 **30/15 mmHg 但 <140/90** 不作为诊断依据，但**需密切随访**。

> 💡 **实用建议**：孕中晚期自备一台经过验证的上臂式电子血压计，每周固定时间测 2～3 次并记录。
> **这比任何"感觉"都能更早发现问题。**

### 3.3.3 治疗原则与关键数字

**降压指征与目标**
- **SBP ≥160 和/或 DBP ≥110 mmHg → 应降压治疗**；
- **SBP ≥140 和/或 DBP ≥90 mmHg → 建议降压治疗**；
- 目标血压：
  - **未并发器官功能损伤**：SBP **130～155**、DBP **80～105 mmHg**；
  - **已并发器官功能损伤**：SBP **130～139**、DBP **80～89 mmHg**；
  - **血压不可低于 130/80 mmHg**（要保证子宫胎盘血流灌注）。

⚠️ **国际目标更严**：**ACOG / CHAP 试验主张 <140/90 mmHg**；**NICE 主张 <135/85 mmHg**。
中国指南的 130～155/80～105 区间相对宽松，**这是中外差异点，不是谁错了**——
引用时需说明依据哪套体系。

**诊断的时间要求（避免误诊）**：
- 首次发现血压升高 → **间隔 4 小时或以上复测**，两次均 ≥140/90 才诊断；
- **≥160/110 者间隔数分钟复测即可诊断**（属急症）。

**安全与禁用的降压药**

| 药物 | 地位 |
|---|---|
| **拉贝洛尔** | ✅ 首选口服之一（Ⅰ-A）；口服 50～150 mg，3～4 次/d |
| **硝苯地平** | ✅ 首选口服之一（Ⅰ-A）；普通片 5～10 mg，3～4 次/d，24 h 总量不超过 60 mg；缓释片 30 mg，1～2 次/d |
| 尼莫地平、尼卡地平、酚妥拉明、硝酸甘油 | 特定情况使用 |
| 硝普钠 | 仅用于其他药物无效的高血压危象，**产前应用不宜超过 4 小时** |
| **ACEI（普利类）/ ARB（沙坦类）** | ❌ **妊娠期禁用**（Ⅱ-2E） |
| 阿替洛尔、哌拉唑嗪 | ❌ 不推荐 |
| 利尿剂 | ⚠️ 妊娠期**一般不用于降压**（防血液浓缩、有效循环血量减少和高凝倾向） |
| **硫酸镁** | ⚠️ **不作为降压药使用**——它的作用是**预防和控制抽搐** |

**硫酸镁（预防抽搐）**：常用方案为负荷量 **4～5 g** 静脉滴注（20 分钟内），
之后 **1～2 g/h** 维持；**国内强调 24 小时总量 25～30 g**（欧美 Pritchard 方案含肌注，方案不同）；
用药期间监测**呼吸（≥16 次/分）、膝反射、尿量（≥25 ml/h）**；
**中毒时用 10% 葡萄糖酸钙解救**。

**硫酸镁用于胎儿神经保护是另一套方案**（剂量更低、时程更短）：
**孕 <32 周**（ACOG：24⁰ᐟ⁷～31⁶ᐟ⁷ 周）即将分娩者，**4 g 静脉负荷 20～30 分钟，继以 1 g/h 维持至分娩或 24 小时**。
**两种用途的剂量方案不同，不可混用。**（具体方案以本院规范为准。）

**预防：低剂量阿司匹林**
- 对象：**子痫前期高风险孕妇**（既往子痫前期史、多胎、慢性高血压、糖尿病、肾脏疾病、
  自身免疫病如 SLE/抗磷脂综合征、肥胖等）；
- 时机：**妊娠 12～16 周开始**（一般不晚于 20 周）；
- 剂量：低剂量阿司匹林。**国际剂量并不统一：ACOG 用 81 mg/d、FIGO 用 150 mg/d；
  国内文献多引用 50～100 mg/d**。"最佳剂量与起止时机尚无定论"，**具体遵医嘱**，通常用至 36 周或分娩前；
- ⚠️ 有出血倾向、消化道溃疡、阿司匹林过敏者需医生评估。

> 来源：[《妊娠期高血压疾病诊治指南（2020）》第一部分全文](http://www.cogonline.com/info/132355552394183047)（中华妇产科杂志 2020,55(4):227-238）

### 3.3.4 HELLP 综合征

- **H**emolysis（溶血）、**E**levated **L**iver enzymes（肝酶升高）、**L**ow **P**latelets（血小板减少）；
- 表现常为**上腹/右上腹疼痛、恶心呕吐、乏力**，**血压和蛋白尿可能并不突出**——这是最容易被误诊为"胃病"的产科急症；
- 属于重度子痫前期范畴，**需立即住院，常需尽快终止妊娠**。

## 3.4 妊娠期糖尿病（GDM）

- **筛查**：妊娠 **24～28 周**做 75 g OGTT；阈值见第 01 章（5.1 / 10.0 / 8.5 mmol/L，任一达标即诊断）；
- **对母胎影响**：巨大儿、肩难产、剖宫产率升高、新生儿低血糖与呼吸窘迫；母亲远期 2 型糖尿病风险显著升高；
- **血糖控制目标（常用）**：空腹 **<5.3 mmol/L**，餐后 1 小时 **<7.8 mmol/L**，餐后 2 小时 **<6.7 mmol/L**
  （**具体目标由医生个体化设定**）；
- **治疗阶梯**：
  1. **医学营养治疗 + 运动**（一线）——分餐（3 主餐 + 2～3 加餐）、控制精制碳水、餐后活动 20～30 分钟；
  2. 1～2 周后血糖未达标 → **加用胰岛素**（中国孕期首选）；
  3. 二甲双胍在部分国家使用，**中国孕期用药需权衡**；
- ⚠️ **不要自行节食**：过度限制碳水会导致酮症，对胎儿神经系统不利；
- **产后随访**：GDM 产妇应在**产后 4～12 周**做 75 g OGTT 重新评估糖代谢，
  此后**至少每 1～3 年筛查一次**（远期 2 型糖尿病风险高）。

**标准之争（为什么"在美国没事、回国被诊断"）**

| 体系 | 标准 |
|---|---|
| **中国 / IADPSG** | 75 g OGTT：空腹 **5.1**、1 h **10.0**、2 h **8.5** mmol/L |
| **英国 NICE NG3** | 空腹 **≥5.6** 和/或 2 h **≥7.8** mmol/L（明显更宽） |
| **美国 ACOG / ADA** | **允许一步法（75 g，IADPSG 阈值）或两步法（50 g 初筛 → 100 g 诊断）** |

同一个孕妇在美国不同机构可能得到不同诊断——**这是 GDM 领域最著名的标准之争，不是误诊**。

## 3.5 早产

- **定义**：妊娠 **≥28 周且 <37 周**分娩（中国口径；国际上早产下限常为 20 周或 24 周）；
  **晚期早产 = 34⁺⁰～36⁺⁶ 周**；
- **发生率**：全球约 **10%**（2020 年约 1340 万例，WHO）；**中国约 6%～7% 且呈上升趋势**；
- **危险因素**：**既往自发性早产（最强的单一危险因素）**、多胎、**宫颈长度 <25 mm**、宫颈手术史、
  子宫畸形、生殖道感染（细菌性阴道病、尿路感染）、吸烟/药物、低 BMI、
  **妊娠间隔 <18 个月**、辅助生殖、**牙周病**、心理应激、社会经济地位低；
- **预测**：
  - **经阴道超声宫颈长度**：孕 16～24 周 **≤25 mm** 为"短宫颈"，是预测自发性早产**最有力的单一指标**；
    **<20 mm 风险更高**；有早产/中孕流产史者可从**孕 14～16 周起每 1～2 周**测量；
  - **胎儿纤连蛋白（fFN）**：阴道后穹窿拭子 **<50 ng/mL** 的**阴性预测值很高**（7 天内分娩风险很低）；
    **阳性只提示风险升高，不能单独作为干预依据**；
- **预防与处理**：
  - **孕酮**：对有早产史、短宫颈者，阴道孕酮或 17-OHPC 有证据支持（**须医生处方**）；
  - **宫颈环扎**：仅对明确指征者（如既往孕中期无痛性流产史 + 宫颈缩短）；
  - **宫缩抑制剂**：用于争取 **48 小时**完成促胎肺成熟与宫内转运，**本身不改善围产儿结局**；
  - **产前糖皮质激素（促胎肺成熟）**：**妊娠 24～34 周**有早产风险者为标准治疗
    （24⁰ᐟ⁷～33⁶ᐟ⁷ 周；34～36⁶ᐟ⁷ 周可共同决策）；常用**倍他米松 12 mg，每 24 小时 1 次 × 2 次**；
  - **硫酸镁胎儿神经保护**：妊娠 **<32 周**即将早产者，可降低脑瘫风险（方案见 3.3.3）；
- **早产儿预后**：与孕周高度相关。**34 周后预后通常良好但仍需监护**，28～32 周需 NICU 支持。

## 3.6 胎儿相关问题

| 问题 | 要点 |
|---|---|
| **胎儿生长受限（FGR/IUGR）** | 诊断基于超声估重低于相应孕周第 10 百分位（需结合多普勒、羊水、生长趋势）；分型（早发/晚发）；监测靠脐动脉多普勒、NST、BPP；**分娩时机需平衡宫内风险与早产风险** |
| **巨大儿** | 估重 ≥4000 g（或 ≥4500 g 为重度）；与 GDM、肥胖相关；增加肩难产、产伤、产后出血风险 |
| **羊水过多 / 过少** | 过多：GDM、胎儿畸形、双胎输血；过少：胎盘功能不全、胎膜早破、胎儿泌尿系异常。**"多喝水"不能治疗羊水过少** |
| **胎膜早破（PROM / PPROM）** | **足月 PROM**：多数建议引产以降低感染；**未足月 PPROM**：期待治疗 + 抗生素 + 促胎肺成熟，严密监测感染。**GBS 阳性需产时抗生素预防** |
| **前置胎盘** | 胎盘覆盖宫颈内口；典型表现为**孕晚期无痛性阴道出血**；**禁止性生活、避免剧烈活动**；多数需剖宫产 |
| **胎盘植入谱系（PAS）** | 前置胎盘 + 剖宫产史者高危；**产后出血与子宫切除风险高**，需在有条件的中心多学科管理 |
| **胎盘早剥** | **突发持续性腹痛 + 阴道出血 + 子宫压痛/板状腹**；可伴胎动减少；**急症，需立即处理** |
| **脐带绕颈** | **非常常见**，多数无不良后果；**不建议仅因绕颈就改剖宫产**；关键是胎动与胎心监护 |
| **脐带脱垂** | 破水后脐带先于胎头脱出 → **急症**，需立即处理（臀高卧位、紧急剖宫产） |
| **双胎** | 需明确绒毛膜性质；并发症包括 TTTS、sIUGR、双胎贫血-多血序列征；分娩方式与时机按绒毛膜性与胎位个体化 |
| **Rh 血型不合** | Rh 阴性孕妇需监测抗 D 抗体；**未致敏者通常在孕 28 周注射抗 D 免疫球蛋白 300 µg，产后 72 小时内再注射 300 µg**（孕 <12 周流产/操作常用 50 µg）。**具体方案遵医嘱** |

## 3.6b 妊娠期肝内胆汁淤积症（ICP）——只表现为"痒"的危险

**为什么单列**：ICP 的唯一早期表现常常是**瘙痒，没有皮疹，也不痛**，
最容易被当成"皮肤干"或"过敏"而延误。它与**死胎、早产、产后出血**风险相关。

**典型表现**
- **手掌、脚掌**为主的瘙痒，**夜间加重**，可蔓延至四肢与躯干；
- **无原发皮疹**（抓痕是继发的）；
- 部分孕妇出现轻度黄疸、尿色加深；
- 多在**孕中晚期**出现，**产后 1～2 周内迅速缓解**。

**诊断与分层（总胆汁酸 TBA 是关键指标）**

| TBA | 分层 | 处理方向 |
|---|---|---|
| **≥10 µmol/L** | 可诊断 ICP（中国《妊娠期肝内胆汁淤积症诊疗指南（2015）》） | 监测 + 治疗 |
| **10～39.9 µmol/L** | **轻度** | 国际（SMFM 2021）认为此区间是否增加不良结局**仍有争议**；多建议 **37 周左右**终止妊娠 |
| **≥40 µmol/L** | **重度 / 高风险**（死胎、早产风险升高） | 通常建议 **孕 36～37 周**终止妊娠 |
| **≥100 µmol/L** | **极高风险** | 需更严密监测与更早终止 |

**治疗**：熊去氧胆酸（UDCA）为主要用药（缓解瘙痒、改善生化指标）；
**维生素 K** 用于凝血功能异常者；**加强胎儿监护**（NST、BPP）；
**分娩时机需在"减少死胎"与"避免早产"之间权衡**，由医生个体化决定。

⚠️ **行动建议**：**孕期出现手掌脚掌瘙痒（尤其夜间加重、无皮疹），请主动就诊并查空腹总胆汁酸 + 肝功能**，
不要自行涂药膏等待。

> 来源：[《妊娠期肝内胆汁淤积症诊疗指南（2015）》](http://seleguide.yiigle.com/uploads/guide_html/%E5%A6%8A%E5%A8%A0%E6%9C%9F%E8%82%9D%E5%86%85%E8%83%86%E6%B1%81%E6%B7%A4%E7%A7%AF%E7%97%87%E8%AF%8A%E7%96%97%E6%8C%87%E5%8D%97%EF%BC%882015%EF%BC%89.html) ·
> [SMFM Consult Series #53（2021）](https://www.sciencedirect.com/science/article/pii/S0002937820312849)

## 3.7 母体合并症与妊娠

| 合并症 | 妊娠期关键点 |
|---|---|
| **甲状腺疾病** | 妊娠期 TSH 参考范围**需用本地区/本单位妊娠特异范围**；甲减需左甲状腺素（LT4），**确认妊娠后剂量常需上调 20%～30%**，发现妊娠应尽快复查甲功；**亚临床甲减 TSH >4.0 mIU/L 通常建议 LT4 治疗**；TPO 抗体阳性者需监测 |
| **癫痫** | **不要自行停药**；多数抗癫痫药可继续使用（丙戊酸致畸风险最高，需专科评估）；补充叶酸剂量常需加大 |
| **哮喘** | **控制不佳的危害大于用药风险**；**吸入性糖皮质激素（布地奈德等）安全且应继续使用**；目标是"控制良好"，急性发作按常规处理 |
| **心脏病** | 需孕前/孕早期心功能评估与多学科管理；某些类型（如重度肺动脉高压）妊娠风险极高 |
| **SLE / 抗磷脂综合征** | **羟氯喹应在孕期继续使用**；孕前需至少 **6 个月疾病缓解**；**抗 Ro/La 抗体阳性者从孕 16 周起每 1～2 周监测胎儿心率**（先天性心脏传导阻滞风险约 1%～2%，复发者升至 15%～20%）；抗磷脂抗体阳性者用**低分子肝素 + 低剂量阿司匹林**。⚠️ **SLE 活动与子痫前期难以鉴别**（补体、尿沉渣、抗 dsDNA 有助于鉴别） |
| **慢性肾病** | 孕前评估血肌酐、eGFR、血压、蛋白尿；**血肌酐 >1.4 mg/dL 或 eGFR <40 者妊娠风险高**；子痫前期风险显著升高，推荐低剂量阿司匹林 |
| **血小板减少** | 最常见为妊娠期血小板减少症（孕中晚期、一般 **>70×10⁹/L**、产后自行恢复）；**<30×10⁹/L 或有出血倾向**时考虑糖皮质激素/IVIG；**血小板 ≥50×10⁹/L 通常可行椎管内麻醉**（需麻醉科评估）。⚠️ **关键是鉴别 ITP 还是 HELLP**——后者需紧急终止妊娠 |
| **乙肝** | 新生儿**出生 12 小时内（最迟 24 小时内）**接种乙肝疫苗 +（HBsAg 阳性母亲所生）**乙肝免疫球蛋白（HBIG）**；**HBV DNA >2×10⁵ IU/mL 的孕妇可在孕 24～28 周起口服替诺福韦（TDF）**以阻断母婴传播 |
| **HIV / 梅毒** | 均已有成熟母婴阻断方案，**关键是早筛查、早治疗** |
| **贫血** | 见第 02 章（中国标准 Hb<110 g/L；SF<20 µg/L） |
| **血栓与抗凝** | 妊娠与产褥期均为 VTE（静脉血栓）高风险期；有血栓史/易栓症者需低分子肝素；**产后风险可持续至产后 6 周** |
| **精神疾病** | **不要自行停精神科药物**；停药复发的危害常大于药物风险；需精神科与产科共同管理 |
| **肥胖** | 与 GDM、子痫前期、巨大儿、剖宫产、麻醉风险、血栓均相关；**孕期不建议减重**，重点是控制增重速度 |
| **感染** | 流感（孕妇为重症高危人群）、新冠、尿路感染、GBS、B19 细小病毒、CMV、寨卡 |

## 3.8 孕期用药安全

### 3.8.1 最重要的一条原则

> **绝对不要自行停用慢性病药物**（癫痫、甲亢/甲减、哮喘、高血压、精神科、抗凝等）。
> **突然停药的危害通常远大于药物本身的风险。** 发现怀孕后应尽快联系原处方医生与产科医生共同调整。

### 3.8.2 FDA 旧分级已废止

FDA 的 A/B/C/D/X 妊娠分级**已被 PLLR（Pregnancy and Lactation Labeling Rule）取代**。
现在药品说明书的"妊娠期用药"部分改为叙述性内容：
**风险摘要、临床考虑、数据**。因此"这是 B 类药所以安全"这类说法已不再适用。

### 3.8.3 常见药物速查（仅作方向参考，不能替代医嘱）

| 用途 | 相对安全/常用 | 需避免或慎用 |
|---|---|---|
| 解热镇痛 | **对乙酰氨基酚**（孕早中期首选，**按最低有效剂量、最短时间**） | **布洛芬等 NSAIDs：孕 20 周后避免**（羊水过少、胎儿肾损伤、动脉导管早闭）；孕 30 周后禁用 |
| 抗生素 | 青霉素类、头孢菌素类、阿奇霉素、克林霉素（多数较安全） | **四环素类**（牙齿/骨骼）、**喹诺酮类**（软骨）、**氨基糖苷类**（耳肾毒性，慎用）、磺胺类（近足月慎用） |
| 抗病毒 | 奥司他韦（流感重症高危孕妇应尽早使用） | 需按专科评估 |
| 降压 | **拉贝洛尔、硝苯地平** | **ACEI/ARB 禁用** |
| 止吐 | 维生素 B6 ± 多西拉敏、昂丹司琼（遵医嘱） | 沙利度胺绝对禁用 |
| 抗组胺/过敏 | 氯雷他定、西替利嗪（多数认为可用） | 第一代抗组胺药注意嗜睡 |
| 抗凝 | **低分子肝素**（不通过胎盘） | **华法林**（致畸，需专科换成肝素） |
| 糖皮质激素 | 促胎肺成熟（地塞米松/倍他米松）为标准治疗 | 长期大剂量全身用需权衡 |
| 抗癫痫 | 拉莫三嗪、左乙拉西坦相对较安全 | **丙戊酸**致畸风险最高 |
| 皮肤外用 | 多数外用制剂全身吸收少 | 维 A 酸类外用需避免 |
| 疫苗 | 灭活疫苗可接种（见 3.9） | **减毒活疫苗孕期禁用**（麻腮风、水痘、鼻喷流感等） |

### 3.8.4 中药与中成药

- **成分复杂、剂量不受监管、多数缺乏孕期安全性数据**；
- 明确的孕期禁忌：**红花、麝香、大黄、番泻叶、水蛭、三棱、莪术、桃仁**等活血/峻下类；
- **凉茶、来路不明的"安胎丸""保胎中药"不建议自行服用**；
- 如已服用，**带上药盒去问产科医生**，不要自行催吐或恐慌。

## 3.9 孕期疫苗接种

| 疫苗 | 孕期建议 |
|---|---|
| **流感疫苗（灭活）** | ✅ **推荐**。中国疾控中心《中国流感疫苗预防接种技术指南（2025—2026）》明确将**孕妇列为优先接种的重点和高风险人群**；所有 ≥6 月龄无禁忌者均应接种，**9～10 月为最佳接种时间**，整个流行季均可接种 |
| **Tdap（百白破）** | ✅ 推荐每次妊娠接种，常在 **27～36 周**（各国窗口略有差异） |
| **新冠疫苗** | 按当地最新免疫策略执行 |
| **RSV（呼吸道合胞病毒）** | 部分国家推荐孕期接种或新生儿用单克隆抗体；**中国内地目前以新生儿单抗为主，政策需按最新公布** |
| 乙肝、狂犬病、破伤风 | 有指征时接种（狂犬病暴露后**必须接种**） |
| **减毒活疫苗**（麻腮风、水痘、鼻喷流感、黄热病等） | ❌ **孕期禁用**，应推迟到产后 |

> 来源：[中国疾控中心《中国流感疫苗预防接种技术指南（2025—2026）》](https://www.chinacdc.cn/jkyj/crb2/bl/lxxgm/jswj_lg/202511/t20251103_313229.html)
